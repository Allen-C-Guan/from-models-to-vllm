# 从模型到 vLLM（From Models to vLLM）—— 系列教学丛书

> 本仓库是这套丛书的**主输出件**（独立 git 仓库，只放书稿产物）。
> 状态：顶层大纲规划中（仓库创建于 2026-10-02）。

## 丛书定位

从最经典的 Transformer 原架构（零魔改、忠于原论文）拆解起步，以已知架构为基础、
经「知识补充 + 架构修改」层层递进到各代模型架构，最终系统进入 vLLM 推理引擎的学习。

- **读者**：具备 AI 基础的计算机学院本科生（线性代数 / 高等数学 / 反向传播 / PyTorch / 计算机基础）。
- **叙事模板（思维层次，非形式标签）**：每项技术从 why→what→how→result 的抽象层次思考与推进——是行文的内在逻辑，不是外在格式；严禁「why：/what：/how：/result：」式标签段落，四层由问题链与过渡句自然缝合，浑然一体。
- **写作三魂**：① **总分总纵深**贯穿一切层级（全书导览俯瞰 → 各章开篇承接/本章总览/节间衔接/章末收拢与「带走的心智」→ 卷末收束回俯瞰）；② **教师视角**（教学优先，不是论文解读——组织服从「构造的逻辑」，前置概念必须搭建到「读者能画出它」，版本考古入考据框）；③ **心智优先**（直觉是灵魂：概念按「直觉→形式化→验证」三步，公式首现配「用人话说」，章末小结的核心是**带走的心智**——细节会忘，心智长存）。
- **行文**：专业为主，穿插克制的直观解释与具体例子；先补最小背景知识再进入主题；卷间逻辑连贯、不重复不断层。
- **公式**：一律 LaTeX 数学环境排版（$...$ / $$...$$），直观、专业，严禁 ASCII 近似；关键公式编号可引用，附符号表与张量形状说明。
- **图表**：合理使用图（架构/数据流/时序/曲线）与表（diff 矩阵/账本/指标对比）直观呈现，不堆砌；优先引用论文原图并标注出处，全书统一编号与交叉引用。
- 丛书级写作规范全文见工作区 `../plan/00-系列总览.md` 第二节（含证据等级、硬件口径、代码交付物标准等硬约束）。

## 仓库结构（仅最终书稿）

```
from-models-to-vllm/
├── README.md
└── book<N>-<书名>/    # 每本书一个目录：每章一个 md，配图在 figures/
```

大纲、代码、调研等**过程件一律不在本仓库**，统一放在上一级工作区：

- `../plan/` —— 顶层大纲（00-系列总览）与各卷大纲（`<bookN-书名>.md`）
- `../code/<bookN-书名>/<章节>/` —— 全部代码实验
- `../research/<bookN-书名>/{papers,articles,sources,notes}/` —— 全部调研材料（论文 / 文章存档 / 源码笔记 / 综述笔记），跨卷共用材料在 `../research/_shared/`

## 每卷写作工序

1. **调研落盘**：`../research/<bookN-书名>/`（论文 = golden truth → 源码 → 优质网络文章）。
2. **卷级大纲**：写入 `../plan/<bookN-书名>.md`，经讨论定稿。
3. **章节草稿**：写作中运行代码验证（代码入 `../code/`，实验须可在工作区环境执行）。
4. **核查**：事实核查（逐条对照论文）+ 跨卷逻辑连贯性审查。
5. **定稿**：入本仓库 `book<N>-<书名>/`。
