# 从模型到 vLLM（From Models to vLLM）—— 系列教学丛书

> 本仓库是这套丛书的**主输出件**（独立 git 仓库，只放书稿产物）。
> 状态：顶层大纲规划中（仓库创建于 2026-10-02）。

## 丛书定位

从最经典的 Transformer 原架构（零魔改、忠于原论文）拆解起步，以已知架构为基础、
经「知识补充 + 架构修改」层层递进到各代模型架构，最终系统进入 vLLM 推理引擎的学习。

- **读者**：具备 AI 基础的计算机学院本科生（线性代数 / 高等数学 / 反向传播 / PyTorch / 计算机基础）。
- **叙事模板**：每项技术 = 现实问题（why）→ 理论 idea（what）→ 落地方案（how，代码与图）→ 效果实证（result）。
- **行文**：专业为主，穿插克制的直观解释与具体例子；先补最小背景知识再进入主题；卷间逻辑连贯、不重复不断层。

## 仓库结构（仅书稿产物）

```
from-models-to-vllm/
├── plan/                        # 顶层大纲（00-系列总览）与各卷大纲（<卷号-书名>.md）
└── books/<卷号-书名>/            # 各卷书稿正文（每章一个 md）与配图 figures/
```

代码实验与调研中间材料**不在本仓库**，统一放在上一级工作区：

- `../code/<卷号-书名>/<章节>/` —— 全部代码实验
- `../research/<卷号-书名>/{papers,articles,sources,notes}/` —— 全部调研材料（论文 / 文章存档 / 源码笔记 / 综述笔记），跨卷共用材料在 `../research/_shared/`

## 每卷写作工序

1. **调研落盘**：`../research/<卷名>/`（论文 = golden truth → 源码 → 优质网络文章）。
2. **卷级大纲**：写入本仓库 `plan/<卷号-书名>.md`，经讨论定稿。
3. **章节草稿**：写作中运行代码验证（代码入 `../code/`，实验须可在工作区环境执行）。
4. **核查**：事实核查（逐条对照论文）+ 跨卷逻辑连贯性审查。
5. **定稿**：入 `books/<卷号-书名>/`。
