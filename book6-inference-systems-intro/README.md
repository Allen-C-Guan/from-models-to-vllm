# Book6《LLM 推理系统原理：计算、存储、调度与生成》

本书面向已具备前五册模型基础、准备学习推理系统的读者。它解释推理技术为什么成立、怎样工作、受到哪些约束；软件架构与源码分别在Book7和Book8展开。操作系统分页、概率采样、排队与异步执行所需背景均在正文首次使用前补齐。

推荐顺序阅读：先认识工作负载与资源，再理解状态、批处理和调度，继而研究Attention、量化和投机，最后回到主机设备协同、多卡与完整服务。每章开篇使用相同坐标的理论地图；图中箭头表示理解关系，不是源码调用顺序。

[打开全书离线连续阅读版](全书连续阅读.html)。数学与正文插图已经嵌入，无需联网渲染；参考文献和历史实验链接需在联网或完整书仓中打开。Markdown正文与图源也保留，方便检索和编辑。
