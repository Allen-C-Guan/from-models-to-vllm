# Book6《LLM 推理系统导论：从自回归数学到服务算法》

> 《从模型到 vLLM》丛书第 6 册 · 前置：Book1-5 全五册（卷间契约：零新架构——八册中唯一不动架构的一册，架构冻结、模型变成工作负载（workload））· 关键锚：Book3 第 10 章 207M 小模型为全书默认服务对象 · 硬件主线：昇腾 Atlas 910B3 本机实测

## 这册书写什么

本册是八册旅程的换边之作。前五册一直站在「造模型的人」这边，这一册站到「伺候模型的人」那边：模型不再是一张待改装的架构图，而是一份工作负载——一组冻结的权重、一本随请求生长的 KV 流水账、一串停不下来的自回归 token 流。引擎的全部工作，就是把这三笔账付得尽量便宜。

全册十四章走三段。先「立账」（第 1-3 章）：立起首 token 时延（TTFT）与每 token 生成时间（TPOT）两把服务尺子，练出 FLOPs、带宽与利用率的手算方法学，扫过 KV cache 压缩的架构、量化、淘汰三线全景。再「造引擎」（第 4-7 章）：亲手写出 v1 到 v4 四版进化的 mini 推理引擎，每一版都从上一版的账本里长出一个必须解决的开销。后「单项深化」（第 8-12 章）：从零推导注意力 kernel 的 online softmax，走完采样与 logits 处理管线，拆解投机解码（speculative decoding）的起草、验证与回滚，盘点量化推理的四家哲学，讲透图执行与并行拓扑——NPUGraph 录放实测提速 11.4×。

造引擎段是本册大项目的主干，四版引擎每一版都是「一笔账逼出一台机器」的标本，每解决一项就用压测数字核销一笔：

- **v1 → v2 连续批处理（continuous batching）**：调度粒度从整批降到迭代步，请求到点就走、生成完即刻退场，静态批 22.8% 的时隙浪费归零；
- **v3 分页 KV（PagedAttention）**：以块为分配单位、按需给块，显存碎片消解，容量准入从 64 条放宽到 724 条；
- **v4 前缀缓存（prefix caching）**：相同前缀只算一次，三场景命中 66.7%-86.6%，TTFT 稳态提速 3.4-5.2×（冷启动尖峰 8.6×）；
- 最后的**分块预填充（chunked prefill）**把长 prefill 切块、解码搭车同行，消掉两阶段干扰，全册以四版引擎的吞吐-延迟总曲线压测收官。

实验的骨架是三层对拍——同一笔账在三个层次各算一遍，层与层的差距不是误差，而是待解释的对象：

- **手算层**：拿到任何 config，一页纸算出每 token 的 FLOPs、字节账与 decode 下限——屋顶线（roofline）给下限、手算给预期；
- **mini 引擎层**：四版引擎的压测读数逐版核销一笔账，每版只动一个变量，台阶正交、读数可归因；
- **真实引擎层**：真实引擎只以黑盒身份对拍登场——同量级小模型 8.9 ms/token 对 mini 引擎 v2 的 59 ms，趋势级可比、绝对数不可比，机制红利与工程红利分账。

每层读数随行标注证据等级与运行栈版本；对拍逼出的纪律同样入册——投机实验的负结果分支预注册在先、跑出 0.63× 如实交卷，执行层等价靠逐位对拍钉死（max|Δ|=0.00e+00）。这套手艺比任何一个数字都长寿。

大项目全程喂给 Book3 训出的 207M 小模型——权重 414 MB、KV 每 token 24 KiB，小到一页纸算得清、一张卡测得出；一切性能数字出自本机 Atlas 910B3 实测，官方标称与实测双口径分列，这是中文第一份 NPU 口径的推理手算账本。

Book2/4/5 三册卷末「瓶颈移向 serving」的移交在此到期：2017 年立下的自回归串行与 O(n²) 两笔旧账清算交货，收束章再以八条新钩把调度决策、块池与哈希、图执行对照、投机解码工程接口一一交到 Book7/8 手上。三层对拍练出的「看到任何引擎数字都说得出卡在哪」的判断力，是本册要让读者带走的东西。

写作上沿两件全册制度：关键知识点配小数字、步骤化的玩具级例子，关键读数与配置原文以原样块呈现的产物实物——账本上的每个数字都摸得到、可复跑。

知识冻结于 2025-2026 的 vLLM v0.30.0 时代生态，且全书保持引擎无关纪律：一切机制以算法与论文身份出场——分页 KV 的「块表」会在第 5 章从零造出来，而任何引擎源码里管块的那个类叫什么，一个字不提；前者是物理，后者是一家工厂的图纸，图纸留给后两册。

## 为谁而写

- **受众**：具备 AI 基础的计算机本科生，以及想系统补齐推理方向底子的工程师。
- **硬前置**：前五册——Book1 的两阶段流程、O(n²) 与自回归串行两笔欠账；Book3 第 6 章 KV 账本与 GQA、第 10 章 207M 服务对象；Book4 的 MoE/MLA/FP8/MTP；Book5 的分类型 KV。
- **软前置**：Book2 第 11 章采样初见；外加矩阵乘计数、PyTorch 与反向传播。
- **不需要**：排队论与马氏链——册内显式声明只用算术。
- **快速通道**：赶时间的读者可走「导览 → 手算 → 造引擎」主线——第 0-1 章完成视角转身与两把尺子、第 2 章立起账本、第 4-7 章跟完四版引擎，深化段与全景章按需回取。
- **体量与读法**：14 章 ≈ 一学期课程。三段式读法——立账段（第 1-3 章）可速读，先建起账本直觉；造引擎段（第 4-7 章）须跟着跑四版代码（code/ 下 ch04…ch07 四个目录）；深化段（第 8-12 章）五章各自独立成艺，可按需取阅。
- **实验环境**：全部实验单卡 Atlas 910B3 可复跑——`source env.sh` 后按各章「动手验证」的命令执行，读数 JSON 底档随仓可查。

| 2009-04 | Roofline 模型（屋顶线模型，Williams-Waterman-Patterson；Berkeley 报告 2008-10 在先，此处取 CACM 刊出版） | 把算力上限与带宽上限折成一张屋顶线图，一眼判定 kernel 卡在计算还是访存，成为本册手算方法学的起点 | [ch01](ch01-视角切换与服务指标.md) |
