# 附录 B 术语与符号

符号按所在公式的局部定义解释。跨专题复用字母时，先查形状和单位，不凭字母猜含义。

## B.1 概念导航

|术语|在本书中的含义|主讲|
|---|---|---|
|prefill / decode|处理已知输入的一段前向／依赖已生成token继续推进|1、4、10|
|TTFT / ITL / TPOT|首输出等待／相邻输出间隔／首输出之后平均每token间隔|1、20|
|吞吐 / 合格吞吐|单位时间完成量／满足指定质量与服务条件的完成量|1、20|
|局部性|邻近位置或近期使用的数据较可能再次使用，支持缓存与复用|2|
|算术强度|规定存储边界的FLOPs除以字节流量|3|
|Roofline / Amdahl|算力与带宽上界／局部改善的端到端限制|3|
|KV cache|因果前缀已经计算的注意力键值状态，不是生成文本缓存|4|
|虚拟页 / 物理页框|地址空间中的固定大小单位／物理存储中的承载单位|5|
|内部 / 外部碎片|分配单位内部余量／单位之间无法满足连续请求的空洞|5|
|COW|共享内容在写入发生分歧时复制，保证写隔离|5、6|
|块表|将逻辑token块映射到物理KV块的元数据|6|
|引用计数 / 可回收|仍有多少拥有者／所有必要使用与保护已结束|6、7、18|
|前缀身份|足以判定此前计算相同的token及模型、位置和其他条件|7|
|基数树|用压缩路径表示公共前缀的索引结构|7|
|连续批处理|以迭代为边界重新决定参与请求|8|
|Little定律|在适用观测边界与稳定条件下，平均人数=到达率×平均停留|9|
|抢占 / 重算 / 换出|暂时让出资源／重建状态／保存并搬回状态|10|
|online softmax|维护最大值、分母和分子，分块更新同一归一化结果|11|
|量化 / 反量化|映射到有限码值／恢复近似数值供后续计算|12|
|校准|用代表性输入估计范围、重要性或重构目标|12、13|
|per-channel / per-token|沿明确的张量轴共享量化参数|12、14|
|logits / 条件概率|未归一化词表分数／在当前前缀条件下的选择分布|15|
|提议分布 / 目标分布|实际产生候选的分布／最终希望保持的生成分布|16|
|接受率 / 接受长度|规定事件的接受概率／一轮实际通过的连续候选数|16、17|
|stream / event|有顺序约束的任务队列／建立完成位置与依赖的事件|18|
|capture / replay|构造可重复任务图的一种方式／再次执行该图|18|
|rank / 通信组|某个协作域中的逻辑参与者编号／该域成员集合|19|
|TP / PP / DP / EP|切张量计算／切层／分请求副本／分专家归属|19|
|SP / CP / PCP / DCP|特定token局部运算分片／上下文分片／prefill与decode的上下文并行|19|
|开放 / 闭合负载|外部计划决定到达／响应完成影响下一次到达|20|

## B.2 常用符号及单位

|符号|意义|单位或形状|
|---|---|---|
|B、T、S|请求数、本轮token数、历史有效长度|计数；不是同一量|
|L、h_q、h_kv、d_h|层数、query头数、KV头数、每头维度|计数|
|d、f、V|隐藏宽度、FFN宽度、词表大小|计数；V在Attention公式也可表示值矩阵|
|F、D、I|运算量、指定边界流量、算术强度|FLOP、byte、FLOP/byte|
|C、W|可持续计算速率与带宽上界|FLOP/s、byte/s；W在量化章表示权重矩阵|
|e、M|每元素字节数、容量|byte/element、byte|
|P、b、T_r|OS页大小、KV块大小、请求r块表|byte、token/block、整数数组|
|m、l、u|稳定softmax最大值、分母、未归一化输出|标量、标量、值向量|
|s、z、q|量化尺度、整数零点、量化码|按编码定义；q在Attention中可表示query|
|p、q、h|目标分布、提议分布、条件前缀|词表概率向量、词表概率向量、token序列|
|α、γ、L_acc|简化接受率、草稿长度、接受长度|概率、token数、token数；以每节定义为准|
|λ、E[S]、ρ|到达率、平均服务时间、简化利用率|请求/s、s/请求、无量纲|

字节采用byte；KiB、MiB、GiB为2的幂，KB、MB、GB为10的幂。FLOPs在本书表示运算总数，FLOP/s表示速率。构造模型、论文测量和本机历史读数不共用“实测”标签。
