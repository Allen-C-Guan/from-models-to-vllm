## 10.2 验证框架：串行墙上的第一道缝

投机的结构三拍子：**起草（draft）**——一个小而快的「猜手」连出 $\gamma$ 个候选 token；**验证（verify）**——大模型（target）**一次前向**同时算这 $\gamma$ 个位置的分布；**回滚（rollback）**——从左到右核对，第一个猜错的位置之后的候选全部作废，从该位置由 target 的分布重新采样一个「正确」token 接着走。

为什么这可能更快？target 一次前向能算 $\gamma$ 个位置的并行前向（prefill 式的批量），比 $\gamma$ 次串行的单步便宜——**用一次并行的验证换多次串行的生成**。串行墙被撞开一道缝：缝的宽度取决于猜手的命中率。

**验证器的数学**（Leviathan et al., ICML 2023；记号契约从论文正字——本册不用 $\tau$，理由见 10.4）：draft 的第 $i$ 个候选来自草稿分布 $q(\cdot)$、target 真分布是 $p(\cdot)$。验证规则：抽 $r \sim U[0,1]$，若 $r < \frac{p(x)}{q(x)}$ 则接受。这个规则保证一件深刻的事：**逐 token 的最终分布与直接从 $p$ 采样严格相同**——投机解码不改变输出分布（不是近似！），只改变产出速度。被拒的位置从 $\max(0, p - q)$ 采修正 token——「把 draft 多给的概率扣掉、按余量采样」，分布守恒的最后一块拼图。分布不变性值得用两行概率论钉死（它是「投机解码无损」的全部依据）：接受概率 = Σ min(p,q)；接受时产出 x 的概率恰为 p(x)（当 p≥q）；被拒时的修正分布把余量 (p−q)⁺ 按比例补齐——两条路合起来，产出分布逐 token 严格等于 p。**数学保证了「快而不歪」**：这是本章与第 9 章采样论的严格衔接。

三个记号（Leviathan 正字）：$\beta$ = 逐前缀接受率（每个位置「前面全中且本位也中」的概率）、$\alpha = E[\beta]$、$c$ = draft 与 target 的单步时间比。期望接受长度（每轮验证平均实得 token 数）：$$E = \frac{1-\alpha^{\gamma+1}}{1-\alpha} \tag{10.1}$$用人话说：$\alpha$ 高时 $E \approx \gamma$（全中带 bonus），$\alpha$ 低时 $E \approx 1$（每轮只保底一个）——**$E$ 是命中率的复利**。加速比大致 $\frac{E}{\gamma c + 1}$（分母=一次 draft 加一次验证的成本）——$\alpha$ 与 $c$ 的联合账决定划算与否。

**例 10.1（构造例：$\gamma{=}4$、$\alpha{=}0.8$ 的手算）**：$E = \frac{1-0.8^5}{1-0.8} = \frac{1-0.328}{0.2} = 3.36$——每轮验证平均实得 3.36 个 token；设 $c{=}0.1$（draft 很快），加速比 $\approx \frac{3.36}{0.4+1} = 2.4\times$。把 $\alpha$ 换成 0.5：$E = 1.94$、加速比 $1.39\times$；$\alpha{=}0.2$：$E{=}1.25$、加速比 $0.89\times$——**赔本**。接受率低于三成，投机的账就翻不正——这个阈值感是本节要带走的。

> **【考据框】三次独立发明**：投机解码在 2022-2023 年被三个团队独立提出：Xia et al.（华为，arXiv:2203.16487，v1 于 2022-03-30，彼时题为 Generalized Aggressive Decoding，后更名）、Leviathan et al.（Google，arXiv:2211.17192，ICML 2023 Oral）、Chen et al.（DeepMind，arXiv:2302.01318）。Leviathan v2 里明确承认 Chen 工作的独立同期性。三篇的验证器数学同构——好想法的时代到了。

## 10.3 猜手的四种形态（proposer 谱系）

验证框架定了，胜负手在猜手。四种形态按「猜手多贵、命中率多高」排列：

四形态的选型账可以预先总览：**命中率**（EAGLE 系 > MTP > draft-model > n-gram）、**部署成本**（n-gram 零成本 < Medusa 复用 target 头 < EAGLE 要训 draft 结构 < draft-model 要第二份权重）、**与架构的耦合**（MTP 只在训练期埋了 MTP 层的模型上可用、EAGLE 要微调、n-gram 即插即用）。没有全能冠军——负载与模型条件决定选型。

**draft-model**：独立训一个小的同分布模型（几层的小 LLaMA）。最朴素：贵在「维护第二个模型」，好在通用。

**Medusa**（arXiv:2401.10774，ICML 2024）：不加模型、在 target 头上加**多个解码头**——每个头并行猜一个位置，头间组成树（树注意力一次性验证多条候选路径）。省了 draft 模型的开销，代价是要训这些头。Medusa-1 报 >2.2× 无损、Medusa-2 报 2.3-3.6×【官方论文】。

**EAGLE 系**（2401.15077 / EAGLE-2 2406.16858 / EAGLE-3 2503.01840）：换了一个洞察——**在特征层猜、不在 token 层猜**。draft 不猜「下一个 token 是什么」而猜「下一个特征向量是什么」（target 的隐层特征自回归性更强、更好猜），从猜出的特征直接出 token；配动态树（EAGLE-2 按置信度建树）与三层特征堆叠（EAGLE-3）。EAGLE-1 在 Llama2-Chat-70B 报 2.7-3.5×，平均接受长度 $\tau \approx 3.8$【官方论文】。**这里正是 K3 的合流点（B5-2 兑现）**：K3 把预训练期的 MTP 层微调成 EAGLE-3 式的 draft——训练目标（Book4 第 8 章）与推理结构（本章）在工业实践里接上了头；报告同时记录了 KDA 状态「原位更新与验证回滚」的张力（只缓存投影输入、片上重建）——混合架构的 draft 验证要为状态回滚付新账，这是 2026 前沿的真实工程问题。

**MTP 与 n-gram**：MTP 作 draft 就是 B4-4 那笔账（DSV3 的 85-90%/1.8×）；n-gram 最极端——**没有模型**，从上下文里找 n 元重复直接抄续写（第 9 章 penalties 的反义词：专门利用重复）。免费但只适合复读型负载。

## 10.4 本机实测：一个如实交卷的负结果

`spec_decode.py` 实现了验证器（忠实口径：确定候选的接受概率 $=p(\text{draft})$）与 n-gram 猜手，在 207M 上双 workload 实测（预注册的负结果分支在此兑现）：

**实物 10.1（本机投机实测，出处：本机实测，Atlas 910B3）**

```text
[repeat] 接受率 0.20 | 每步实得 0.03 tok | 加速比 0.02-0.04（投机臂 47 ms/步 vs 基线臂 ~1.2 ms/token）
[open]   接受率 ≈0   | （n-gram 候选命中率近零——开放生成无重复可抄）
```

加速比远小于 1——但这不是「投机解码不行」的证据，是三层归因的教学现场：**其一，模型能力**。1000 步弱模型没学会复读——即便 repeat 负载里上下文有现成重复，target 分布对续写 token 的概率也只有两成左右（$\alpha{=}0.2$）。这个负结果的教学价值值得再点一层：它演示了**预注册**怎么保护结论的诚实——实验设计时就把「加速比≤1 如实报」写进预注册（卷级大纲 ch10 节），跑出来果然 ≤1，于是我们拿到「归因清晰的负结果」而不是「调参调到正的脆弱正结果」。工程研究的纪律与运气无关。回到式 (10.1)：E=1.25、理论加速约 0.9——**理论与实测互证：alpha 低于三成，账面本来就翻不正**。工业数字（85-90% 接受率、1.8×-3.5×）的前提是强模型对自身输出的高置信——$\alpha$ 是模型与 draft 的联合属性，不是机制的属性。**其二，计时口径**。教学实现的两臂不对称（投机臂每次前向整段 ctx+draft、基线臂短窗贪心）——真实引擎两臂共享 KV 与执行层，账要公平得多。**其三，猜手形态**。n-gram 是最弱的猜手，EAGLE/MTP 的命中率天差地别。三层拨开，机制的边界清楚了：**投机解码是命中率生意——模型越自信、draft 越懂模型，生意越红火**。

## 10.5 本章小结

F2（自回归串行，2017 年的欠账）、B4-4（MTP 作 draft，带着三条厂商数字）、B5-2（K3 的合流）三笔账在此合销——第 9 章末预告的「beam 还魂」也兑现了：验证器一次比 $\gamma$ 个候选，正是 beam search「一次比多条」思想在采样时代的转世。带走的心智：**投机解码不是赌博——是花小钱批发「验证」；输出分布严格不变（数学保证），变的只有速度；而速度的全部秘密在 $\alpha$：模型与猜手的默契度是这门生意的本金**。本册实验的一个负结果与三条工业数字并排陈列——机制、边界、前提，一页讲完。
