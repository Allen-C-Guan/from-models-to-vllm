# vLLM V1 架构剖析：全景、协作与设计原则

读者只需具备模型架构基础和 Book6 的推理理论知识。本书帮助读者解释 vLLM 的整体组成、组件协作与设计取舍，并判断一段源码在系统中的位置。

**[打开全书连续阅读版](全书连续阅读.html)**：12 章、4 附录、36 张已渲染中文软件架构图；图片内嵌，正文可独立阅读。附录实践源码随目录保存。

源码锚为 vLLM v0.30.0／ced6857；Ascend 实现使用另行标注的源码观察点。例子为教学构造，本次重写未进行硬件性能实验。源码导航位于各章末，跳过导航不影响正文理解。
