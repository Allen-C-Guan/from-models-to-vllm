# 前沿混合架构：稀疏读取、固定状态与长上下文

沿Transformer蓝本继续改造注意力：从窗口、可学习稀疏到GDN与KDA，再将状态更新、全局检索、前馈和位置机制放到完整模型中考察。保留论文比较、参数计算和教学实践，解释每次改动的原因、收益和代价。

读者具备本科线代、高数、概率及前四册知识即可；无需先完成前册的长训练。数学单元开头先说明结论与模型意义，再进入推导。第5章为完整的线性注意力与GDN长章。

## 编年史

下表按所列材料的时间整理教学线索，不用于判定历史首创（时间口径：论文取 arXiv v1 提交月；无 arXiv 者取会议/官方发布月；模型/系统取官方首次发布月；时间列括注与表下注为双时点裁定与证据口径）：

| 时间 | 名称 | 贡献 | 详见 |
|---|---|---|---|
| 2017-06 | Transformer（《Attention Is All You Need》，Vaswani et al.） | 自注意力连接掩码允许的序列位置，训练时可并行处理各位置；自回归生成仍按依赖逐步进行 | [ch01](ch01-三条突围路线.md) |
| 2020-06 | 线性注意力（Linear Attention，Katharopoulos 等） | 用有限维特征映射定义核注意力，固定状态维数时序列工作量可随长度线性增长；不是精确softmax的通用线性算法 | [ch05](ch05-线性注意力与GDN.md) |
| 2020-10 | ViT（Vision Transformer，Dosovitskiy 等） | 将像素块线性投影成序列，配合位置表示输入Transformer；大数据实验验证其视觉分类能力 | [ch10](ch10-能力扩展专题.md) |
| 2021-02 | 快速权重编程器（Fast Weight Programmers，delta rule 正身） | 连接线性注意力与快速权重记忆，Delta规则沿键方向纠正预测残差；检索效果仍依赖键与任务条件 | [ch05](ch05-线性注意力与GDN.md) |
| 2021-02（v1 提交 02-26、滚入 3 月编号；模型 2021-01 先行） | CLIP（对比图文预训练） | 用4亿图文对训练双编码器与共同投影，以对比目标支持零样本分类；不直接给出逐词生成分布 | [ch10](ch10-能力扩展专题.md) |
| 2021-10（v1 提交 10-31、滚入 11 月编号） | S4（结构化状态空间模型） | 用结构化状态空间参数化高效生成卷积核，也可按固定状态递推；卷积训练与逐步推理复杂度须分开 | [ch05](ch05-线性注意力与GDN.md) |
