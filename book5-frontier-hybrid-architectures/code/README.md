# 配套代码

各章目录保留对应的教学实现和实验脚本。CPU数学入门例子：

```bash
python code/ch05/gdn-math/verify.py
```

它打印本章小例子的逐token输出与末状态，并比较不同块长、梯度和分段续算。依赖PyTorch，不加载模型权重。

原有整机与训练脚本保留历史Mac/MPS设备口径，部分脚本依赖前册代码、工作区数据与下载权重，不能仅下载单文件即运行。运行前查看脚本参数、设备和导入路径；新环境中的数值检查不代表已重跑历史长训练。各章命令若使用`source env.sh`，应在完整写作工作区执行，书仓本身不包含该环境脚本。

第3章块稀疏选择已修复未来信息进入块选择的问题：仅用块首查询与完整历史块选择，并显式包含当前块。旧训练曲线来自修复前版本，不能证明修复后模型质量。第6章教学KDA层明确要求键值头维相同，核心递推函数支持不同键值维；输出门投影到头拼接维，模型隐藏宽不必等于该维度。

代码中日志默认写入运行布局对应的log目录；不要把生成的日志、权重或环境提交到书仓。
