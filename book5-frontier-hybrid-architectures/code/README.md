# 配套代码

各章目录保留对应的教学实现和实验脚本。CPU 数学入门例子：

```bash
python code/ch05/gdn-math/verify.py --out-name run1
```

它打印本章小例子的逐 token 输出与末状态，并比较不同块长、梯度和分段续算。依赖PyTorch与SymPy，不加载模型权重；输出包含数学案例与205项检查结果，重复运行请换输出名。另可运行`python code/ch08/position_checks.py --out-name run1`检查位置公式边界。

原有整机与训练脚本保留历史 Mac/MPS 设备口径，部分脚本依赖前册代码、工作区数据与下载权重，仅下载单个文件并不能直接运行。运行前查看脚本参数、设备和导入路径；新环境中的数值检查不代表已重跑历史长训练。各章命令若使用 `source env.sh`，应在完整写作工作区执行，书仓本身不包含该环境脚本。

第5章旧MPS scaling脚本的序列/头轴曾传反，原斜率不再作为复杂度证据。第6章旧`--resume`实际只恢复模型权重，现明确为`--warm-start`。第7章124.627M的LatentMoE消融与44.278M量化模拟是不同机器。

第3章的块稀疏选择已修复未来信息进入块选择的问题：仅用块首查询与完整历史块选择，并显式包含当前块。旧训练曲线来自修复前版本，不能证明修复后模型质量。第6章的教学 KDA 层明确要求键值头维相同，核心递推函数支持不同键值维；输出门投影到头拼接维，模型隐藏宽不必等于该维度。

日志与缓存写入工作区或独立运行目录的`log/`。第9章召回checkpoint按输出名隔离，续接用`--resume`；改变目标总步数会改变cosine日程。第10章默认只读本地模型，首次下载须`--download-models`，历史800步需显式`--steps 800`；仅保存投影终态，不声称支持完整断点续训。第11章固定仓库revision、仅Range读取分片头，`--offline`可复用缓存，报告用`--out-name`隔离。
