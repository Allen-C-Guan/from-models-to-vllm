# Transformer原典：从序列建模到完整计算

这是《从模型到vLLM》的第一册。我们从一台翻译机的任务契约开始，沿循环记忆、按需读取与注意力整机的演变，解释Transformer为何这样设计、公式怎样得到，以及每项性质的适用边界。

读者应熟悉本科线性代数、微积分和概率基础；模型特有概念在首次使用时建立。贯穿案例是“我 爱 猫”到“i love cats”，训练与生成沿用同一任务。
