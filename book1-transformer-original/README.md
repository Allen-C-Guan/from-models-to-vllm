# Book1《Transformer 原典：2017 原架构完全拆解》

> 《从模型到 vLLM》丛书第一册 · 前置：无——丛书从这里发车 · 论文锚《Attention Is All You Need》arXiv:1706.03762 v7 · 时间冻结 2017、零魔改 · 实验 Mac/MPS 本机实测（定稿历史事实）

## 这册书写什么

八册旅程的第一站：把时间冻结在 2017 年，对《Attention Is All You Need》的原架构做一次零魔改拆解——RMSNorm（均方根归一化）、旋转位置编码（RoPE）、分组查询注意力（GQA）等后续改进一概不提前引入，只在书中的「欠账框」里露一面。这样做的代价是看不到「最新版」，收益是每个设计在 2017 年当场的理由都看得清——不被后见之明污染。

叙事视角不是论文领读，而是「构造的逻辑」：陪着当年的工程师把每个决策重做一遍，每一步先问「我们被什么卡住了」，再看「他们用什么换了什么」。组织顺序服从造机器的逻辑——下一步需要什么就先教什么；论文是证据来源与重构对象，不是导游。

全书是一条造机器的旅程，分五段走，迷路的时候回到这张地图：

- **出发**（导览 + 第 1 章）：拆开 2014 年的 seq2seq（序列到序列）旧机器，看清容量墙与串行墙两道坎——为什么需要新机器；
- **零件铺**（第 2-6 章）：亲手造五件零件——缩放点积注意力（scaled dot-product attention）、多头注意力（multi-head attention）、三种注意力岗位、正弦位置编码（sinusoidal position encoding）、前馈网络（feed-forward network，FFN）与残差归一化；
- **组装**（第 7-8 章）：按论文 §3.4 图纸零重写装机，备好 2017 年原汁原味的训练配方——整机长什么样、用什么点火；
- **点火**（第 9-10 章）：缩尺寸、上真数据，让机器跑起来，用数字检验每个设计的贡献；
- **收官**（第 11 章）：清点遗产与欠账，拿到通往后续七册的地图。

点火段就是本册的大项目：一台 9.42M 参数的翻译机在一台普通笔记本的 GPU 上约 3.7 分钟训完，连同两台门控循环单元（GRU）基线的三模型全流程约 20 分钟，Multi30K 英德测试集上拿到 21.87 BLEU；再以 13 配置的消融（ablation）网格与种子噪声判据（σ=0.45）对论文 Table 3 做趋势级验货——不比绝对数字，比方向是否一致。

本册全部实验数字为本机真实跑出（Mac/MPS 口径，属定稿历史事实，不回改）；连原论文七个版本之间的数字漂移都做了版本考古，全书引用一律锚定 arXiv:1706.03762 v7，引用纪律全程可复核。

三条线在旅程里一直陪着你，盯住它们，这本书会读成一个故事：

- **一条代码线**：第 2-6 章每章交付一块拼图，第 7 章组装，第 9 章点火——读完拥有的不是散落的脚本，而是一台整机；零件怎么一步步变成整机，就是架构怎么一步步长出来的镜像；
- **两堵墙**：容量墙与串行墙在第 1 章立起来，零件铺的注意力在拆容量墙；清点时会发现串行墙只拆了一半——拆不干净的墙，就是欠账；
- **一本账**：参数量、显存、重算三笔账，从第 2 章第一次手算注意力矩阵的字节起反复练——这个账本习惯是后续七册一切工程叙事的通用货币。

合上这册书，带走三样东西：一台每个螺丝都亲手拧过的机器、一条能解释每个设计选择的推理链、一张欠账地图——O(n²) 复杂度、自回归（autoregressive）串行、容量焦虑三笔欠账，都登记在这张地图上。

每笔债都有还址：O(n²) 交给 Book5 的注意力突围路线与 Book6 的 KV cache 压缩和注意力 kernel；自回归串行由 Book6 的 prefill/decode 两阶段与投机解码（speculative decoding）、Book4 的多词元预测（MTP）接手；容量焦虑则长成长上下文主线，从 Book3 的外推（extrapolation）工程线一路接到 Book5 的 1M 上下文。

机器造好了，下一站交棒 Book2《预训练革命》：拿互联网去喂它。

## 为谁而写

写给具备 AI 基础的计算机本科生：线性代数与矩阵运算、高数、反向传播、PyTorch 基础即可，无需任何前置册——丛书从这里发车。

每章自带「最小背景栏」——循环神经网络（RNN）与长短期记忆网络（LSTM）的黑盒图、softmax 梯度、BLEU 速览、和角公式……——缺什么现场补，补到「能凭记忆画出来」的程度；每章开头另有一节「从全书到这里」的定位点：上一章走到哪、带着什么问题、本章要回答什么，在细节里迷路了就去读它。

体量 12 章，约合一学期课程。代码线从第 2 章起层层拼装，建议顺读、跳章会断件；本册是整套书的起点，没有快速通道——从这里顺读就是最短的路。

每章末「动手验证」给出全命令与固定种子，主线数字可在自家笔记本亲手复现：三模型全流程约 20 分钟；第 10 章消融网格全量 52.4 分钟，读者档（必做三行 + base 单种子）约 17 分钟，其余行给脚本、由作者侧跑成书。

书中另有四类插入框各司其职——借用框、实现对照框、考据框、欠账框——框内都是支线，可按兴趣选读，跳过不影响主线。
