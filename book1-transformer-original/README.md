# Book1《Transformer 原典：从序列建模到完整计算》

本册从2014年的序列到序列模型出发，逐步构造2017年原版Transformer。读者应熟悉本科线性代数、微积分与概率，以及基本的神经网络训练；模型特有的新概念和推导桥梁在正文中补齐。

本册建立后续各册共同改造的蓝本：先理解固定状态与循环依赖带来的限制，再推导注意力、多头、位置编码、FFN、残差和归一化，最后把完整模型接入训练、生成和评测。后续的预训练目标、归一化、位置方法和缓存共享，都能回到这台整机上判断改了哪里、为什么改、又付出了什么。

## 怎样阅读

第0—1章说明整机目标与历史问题，第2—6章逐个建立部件，第7—8章组装模型和训练配方，第9—10章保留完整Multi30K翻译项目与消融，第11章回顾设计边界并连接后续各册。建议第一次按顺序阅读。

数学推导单元先交代结论和模型用途，再展开定义、形状、关键等号与小例子。只读这些首段可把握主线；需要理解细节时，应沿正文推导和短代码核验。重点不仅是记住公式，还包括知道它依赖哪些条件，以及改变条件后哪一步会失效。

正文以[《Attention Is All You Need》v7](https://arxiv.org/abs/1706.03762v7)为主要阅读锚，但讨论的是2017年架构。论文版本差异在相邻说明和第11章保留；现代框架实现与历史论文分开比较。[参考文献](参考文献.md)列出主要原始资料。

## 配套项目与实验口径

[第9章项目](code/ch09/README.md)包含数据准备、分词、Transformer与两种GRU、训练、解码、BLEU和长度评测；[第10章代码](code/ch10/ablation.py)提供消融网格。代码没有缩成一个只能演示概念的合成任务。

文中M5 Pro/MPS训练时长、BLEU、曲线和消融均为2026年10月的历史记录，不是本轮CPU核验或NPU测量。当前代码修正了GRU填充处理、束搜索停止和交叉注意力探针；没有重跑整套训练，因此旧成绩不能被当作修正后的复现保证。第9—10章保留这些限制及其对解释的影响。

运行章末命令时，以本册目录为当前目录，先激活自己的Python环境。核心组件使用PyTorch；绘图需Matplotlib，完整翻译项目另需sentencepiece、datasets与sacrebleu。书中不会自动安装依赖，也不附数据或检查点。数据与实验产物写入`log/`；可设置`BOOK1_LOG_ROOT`为其他目录。在本项目工作区使用时，先在工作区根目录激活已有`env.sh`，再进入本册运行，工具缓存沿用工作区配置。

原版结构与现代工程应分开读：本册默认保留post-LN、ReLU、正弦PE与双塔结构；朴素解码为了教学会重算前缀，但这种重算并非自回归模型的必然要求，KV复用在后续册展开。
