# 参考文献与阅读位置

正文的数学推导、教学构造与历史实验不等同于论文原结论。以下资料用于对照机制与原始实验；引用具体数值时，以正文所列版本、节号和条件为准。

- **Transformer**：[《Attention Is All You Need》](https://arxiv.org/abs/1706.03762v7)。第2—10章结构、配方、消融；第11章版本比较。
- **seq2seq**：[《Sequence to Sequence Learning with Neural Networks》](https://arxiv.org/abs/1409.3215v3)。第1章固定状态、源句逆转与训练。
- **GRU**：[《Learning Phrase Representations using RNN Encoder–Decoder》](https://arxiv.org/abs/1406.1078v3)。第1/9章门控循环。
- **固定向量分析**：[《On the Properties of Neural Machine Translation》](https://arxiv.org/abs/1409.1259)。第1章长句与词表实验。
- **Bahdanau**：[《Neural Machine Translation by Jointly Learning to Align and Translate》](https://arxiv.org/abs/1409.0473v7)。第1/4/9章软对齐。
- **Luong**：[《Effective Approaches to Attention-based Neural Machine Translation》](https://aclanthology.org/D15-1166/)。第2章打分函数与比较。
- **GNMT**：[《Google’s Neural Machine Translation System》](https://arxiv.org/abs/1609.08144v2)。第1/8章系统与长度惩罚。
- **ConvS2S**：[《Convolutional Sequence to Sequence Learning》](https://arxiv.org/abs/1705.03122v3)。第1/5/11章卷积与位置；转引Transformer表时另保留其v2口径。
- **LayerNorm**：[《Layer Normalization》](https://arxiv.org/abs/1607.06450v1)。第6章归一化。
- **残差**：[《Deep Residual Learning for Image Recognition》](https://arxiv.org/abs/1512.03385)。第6章残差动机。
- **post/pre-LN**：[《On Layer Normalization in the Transformer Architecture》](https://proceedings.mlr.press/v119/xiong20b.html)。第6章后续分析，不回写成2017作者已证结论。
- **Adam**：[《Adam: A Method for Stochastic Optimization》](https://arxiv.org/abs/1412.6980v9)。第8章矩估计与偏差修正。
- **标签平滑**：[《Rethinking the Inception Architecture for Computer Vision》](https://arxiv.org/abs/1512.00567v3)。第8章目标分布定义。
- **BPE**：[《Neural Machine Translation of Rare Words with Subword Units》](https://aclanthology.org/P16-1162/)。第8/9章子词入口。
- **权重共享**：[《Using the Output Embedding to Improve Language Models》](https://aclanthology.org/E17-2025/)。第7章输入输出共享。
- **BLEU**：[《BLEU: a Method for Automatic Evaluation of Machine Translation》](https://aclanthology.org/P02-1040/)。第9章截断计数与长度惩罚。

Transformer的[最初版本](https://arxiv.org/abs/1706.03762v1)、[v2](https://arxiv.org/abs/1706.03762v2)与[会议版本](https://papers.nips.cc/paper_files/paper/2017/hash/3f5ee243547dee91fbd053c1c4a845aa-Abstract.html)用于第11章版本比较，不能混用其表格、公式与结果口径。
