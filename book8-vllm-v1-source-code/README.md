# vLLM V1 源码剖析：从对象协作到运行现场

承接新版 Book7 的全局架构认知，本书打开上游 vLLM v0.30.0 的对象、契约、关键源码与阶段性数据。Ascend 是运行观测与平台适配分支，主线仍是上游实现。

**[打开全书连续阅读版](全书连续阅读.html)**：28 章、4 篇附录与基础实践说明，87 张图已内嵌，可离线阅读。每章复用固定坐标地图，以 UML、注明条件的调用路径、中文教学注释源码与对象现场共同解释机制。

从 Qwen3-0.6B 的两条短请求 A/B 开始，再加入 C。端到端变体与 CPU 契约实验分别保存；不把不同进程、不同运行或构造例拼成一次真实执行。[实验范围与复现](appendix-b-全册实验与复现.md)列出了每项证据的实际边界。
