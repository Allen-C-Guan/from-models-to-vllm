## 判据（GELU-4C vs SwiGLU-8/3C，参数对齐档）

1. **质量主判据**：main 档（d=768 零误差参数对齐）两臂 eval_final 之差与同一 ±0.02 nat 噪声带
   对照（带宽口径同 ch02）。
   - **预注册预期 = 负结果预案**：mini 档（49.6M 参数、41M token、5000 步）差距大概率落在噪声带内。
     依据：Shazeer 2020 Table 1 长跑列的 SwiGLU 优势 ≈ 0.04 log-ppl 出现在 768 宽、数亿 token、
     ≥6.5 万步的档位；本实验 token 量小一个数量级以上。
   - 若差落在带内：写「本规模未复现显著差」的**负结论**，并引论文档位说明差距本就小——这本身是
     「组件改进随规模显影」的教学点。
   - 若 |Δ| > 0.02 nat：两种处置——(a) 方向与论文一致（swiglu83 更低）→ 如实报数字 + 档位限定；
     (b) 方向相反 → 先查取整/初始化/优化异常，用 sanity512 档与参数账复核后再定性。
2. **sanity512 档（--cells 选做，不作显著性判读）**：d=512 档只演示**取整盈余账**——
   d_ff = ⌈8/3·512⌉₂₅₆ = 1536，每层 FFN 参数 3·512·1536 = 2,359,296 比 gelu4c 的
   2·512·2048 = 2,097,152 **盈余 +12.5%**（参数不对齐时「谁赢」没有单变量意义，这正是主实验
   选 768 零误差档的原因）。

## 执行记录（2026-10-04，判读按上述条款）

- fast（1000 步）：|Δ| = 0.1366 nat，方向与论文一致（swiglu83 更低）——按处置 (a) 如实报数 +
  档位限定；500 步中途差 0.076 → 1000 步 0.137，差距随训练放大。
- full（5000 步，主判读）：|Δ| = 0.1952 nat（swiglu83 更低），负结果预案未兑现——按处置 (a)：
  如实报数 + 档位限定。差距轨迹：500 步 0.073 → 2500 步峰值 0.249 → 退火收尾收窄至 0.195，
  全程未落回带内；两臂初始 loss 9.13–9.15、无发散。
- 判读纪律：0.195 **不得**与论文 0.04 log-ppl 并列为「复现」——档位（49.6M/41M token/8k 词表
  vs 768 宽数十亿 token/52 万步）、数据、目标全不同，可转移结论只有方向（同预算门控占优）；
  「小档差距反而更大」登记为悬案（候选解释 = 欠训练期乘性梯度通路先兑现，单种子不足以裁决）。
