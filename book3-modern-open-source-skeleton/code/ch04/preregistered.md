## 判据（wpe vs RoPE：训 512 测 2048）

1. **同窗不劣化判据（方向）**：rope 臂同窗（512 固定窗）eval_final **不劣于** wpe 臂
   （预期 rope ≤ wpe，或差落在批一登记的单种子路径方差量级内）。若 rope 显著劣化且优化异常检查
   无异常 → 登记「本档 RoPE 同窗受损」悬案（换装初始化差异为候选解释），不写「RoPE 更差」结论句。
2. **外推退化方向（4×，RoPE 臂）**：`extrap_2048.loss > eval_final`（同臂 512 窗）——软墙方向：
   RoPE 无查表上限能前向，但越窗位置有代价。位置分桶方向：`pos[512:1536]` 与 `pos[1536:2048]`
   各桶 ≥ `pos[0:512]`（越界段不优于训练段）。
3. **负结果处置**：若 2048 不比 512 差（短训弱模型位置利用不足时可能——探针 G 600 步 8k 只
   +0.09 nat 的先例），如实报「本档未现显著外推退化」，正文以分桶形态与 ch7 full 档补强叙事，
   不强行「崩」字。
4. **wpe 硬墙（定性素材，无数值判据）**：wpe 臂 2048 前向必触发 assert、裸查表必 IndexError——
   `wall_2048` 字段完整记录两种报错（N2「1024 位之墙」的硬墙证据链）。
5. 参数差如实标注：rope 臂少 wpe 表 524,288（−2.2%，位置参数 wpe→0）——两臂参数天然不对齐，
   判读同窗质量时带此限定。
