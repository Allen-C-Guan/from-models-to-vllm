## 判据（LN vs RMSNorm）

1. **质量主判据——等价性检验**：两臂末段固定窗 eval loss（eval_final，各 401,408 token fp32）之差

   $$
   |\Delta| = |\text{eval}_{\text{base}} - \text{eval}_{\text{rmsnorm}}| \le 0.02\ \text{nat} \Rightarrow \textbf{等价成立}
   $$

   - 噪声带 ±0.02 nat 的口径来源：参照 Book2 ch8 的 eval 噪声协议（eval 池逐 token loss std=2.50
     实测 → 401,408 token 的采样 se≈0.004）；带宽取 ~5×eval-se。预期结论与 RMSNorm 论文
     Transformer 档「RMS≈LN 质量持平」一致。
   - 若 |Δ| > 0.02 nat：**不得**直接写「RMSNorm 更好/更差」——先查单臂是否优化异常（发散标记/
     曲线形态），再决定是否补第二 seed 复核；正文引用差异时必须带步数与档位限定。
2. **速度副判据（单独报，不与质量混算）**：两臂稳态 sec/step（丢前 20 步预热）+ wall-clock
   同表并列；论文 7-9% 加速（2019 V100 fp32 语境）与本机 bf16 autocast 实测双口径呈现，
   严禁混用（纪律守门：RNN 档 64% 加速数字严禁挪用到 Transformer）。
3. **参考量（不作判据）**：tail300 train loss 差——训练损失含 bf16 噪声与批间方差，只作曲线
   形态佐证，判读一律以固定窗 eval 为准。

## 执行记录（2026-10-04，判读按上述条款）

- fast（1000 步）：|Δ| = 0.0108 nat ≤ 0.02 → 等价成立。
- full（5000 步，主判读）：|Δ| = 0.0430 nat，**超带**。按条款执行：①两臂 diverged=False、
  曲线平滑下降，无优化异常；②逐步差序列（RMSNorm − LayerNorm，每 500 步一评）为
  0.010/0.024/−0.0005/0.013/0.015/0.018/0.018/0.038/0.042/0.043——差异集中在退火后段（≥3500 步），
  fast 档（完全退火）反而带内，形态 = 训练后期路径敏感；③结论口径：单种子、23.6M 档、41M token
  口径下，不作「RMSNorm 更差」的判定，正文带档位与种子限定引用。

  预登记第二种子；ch3 判据与本判据同时预注册、仍用 ±0.02，其判读已带档位与种子限定。
