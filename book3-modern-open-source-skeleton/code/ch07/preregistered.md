## ppl 方向判据

1. **直接外推退化（软墙）**：`none@8192` 差于 `none@2048`（同窗基线）。若不差 → 负结果如实报
   （600 步探针 G 8k 仅 +0.09 nat 先例；弱模型退化温和是已知形态），以分桶与 16k 补强。
2. **干预救回方向**：`pi@8192`、`ntk@8192`、`yarn_lite@8192` 均不差于 `none@8192`。
3. **PI 同窗税**：`pi@2048` 差于 `none@2048`（均匀压缩伤原窗分辨率——PI 论文 §3.2 定性句的本机版）。
4. **8k 档干预间排序（预期级，容许并列）**：`yarn_lite ≤ ntk ≤ pi ≤ none`。
5. **16k 二次越界**：各干预相对其 8k 值再次退化（干预按 8k 设计）；`none@16384` 最糟方向预期；
   干预间排序是否保持如实报。
6. **分桶方向**：`none@8192` 的 `pos[2048:4096]`、`pos[4096:8192]` ≥ `pos[0:2048]`（训练窗外段
   更差）；有效干预应压缩桶间差。

## passkey 方向判据（in/out-window 双口径）

1. **弱模型条款（前置）**：若 in-window（1536）基线准确率≈0（600 步探针 0/8 先例），则全部数字
   **仅作协议验证**，不作质量结论——预注册锁定，防止对弱模型过度解读。
2. **基线对照**：in-window（1536）应高于 out-window（4096/8192）的 `none`（越窗检索退化方向）。
3. **干预救回方向**：out-window 各档 `pi/ntk/yarn_lite` 准确率 ≥ `none`；干预间排序容许并列、如实报。
4. **双口径脱钩条款**：ppl 与 passkey 排序**允许不一致**（「ppl 高 ≠ 检索失效」正是双口径的论点，
   YaRN 附录 B.2 原句锚）；两指标分别如实报，不强行调和。

## 共用处置条款

- 方向预注册、不设量值（承批一带宽校准教训：±0.02 nat 带覆盖评测采样噪声、覆盖不了单种子优化
  路径方差）——每条判据只锁「预期方向 + 反向时的处置条款」；任何方向反转先走优化异常检查
  （发散标记/曲线形态/tail 与 eval 同向性），再决定是否登记悬案或补第二种子。
- 全部结论带「单种子 / fast 或 full 档 / 步数」三限定；fast 完全退火、full 日程更长，不跨档比绝对值。
- 发散守门 loss>100 或非有限即断；速度数字单独报，不与质量混算。
