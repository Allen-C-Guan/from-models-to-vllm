## 判据（词表扫描四臂，fast-only）

1. **比较轴预注册**：四臂同 token 预算 = 同算力（8192 tok/步 × 同步数）；**跨臂质量唯一可比口径 =
   eval_bpb**（bits per byte，按各臂首 2000 篇同文本的 bytes/token 归一）——`eval_nats_per_token`
   跨词表**不可比**（V 越大每 token 覆盖字节越多，nats/token 天然越高），只作臂内曲线字段。
2. **确定性方向（几何/分词事实，非实验判据）**：V↑ → bytes_per_token↓（压缩率升）、嵌入占比↑
   （tied 单份 V·d/总参）、参数总量↑（(V−8192)·512 线性）。这三条是账，不是实验结论。
3. **质量方向不预注册**：mini 档 1000 步单种子下 V 的 bpb 效应两侧皆有先例（大 V 嵌入行训练不足
   vs 小 V 压缩损失），预注册为**开放问题**——如实报 bpb 排序 + 档位限定，正文写「本档观察」不写
   结论句。
4. **速度副判据**：sec_per_step 随 V 变化如实报（softmax/嵌入行数变化的边际影响，预期小）。
