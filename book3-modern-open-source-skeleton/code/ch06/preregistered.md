## 判据（MHA(h_kv=8) / GQA-4(h_kv=4) / MQA(h_kv=1) 组数扫描）

1. **质量主判据（方向）**：eval_final 排序 `mha8 ≤ gqa4 ≤ mqa1`（KV 头减少 → 质量单调变差或持平）。
   - 若 `gqa4` 与 `mha8` 差落在批一路径方差量级内 → 写「GQA-4 近似无损」（对齐 GQA 论文
     「GQA-8 与 MHA 差 0.1 甜点」的方向叙事，带档位限定）。
   - 若 `mqa1` 反超 `gqa4` 或排序反转 → 先查优化异常；无异常则登记悬案（模块档不做参数补齐、
     MQA 参数最少反而训练更快收敛是候选解释），**不写「MQA 更好」结论句**。
2. **质量-KV 反向关系（本章主判据）**：质量降序方向（mha8→mqa1 变差或持平）与 KV/token 字节降序
   （12,288→6,144→1,536 B，严格 8:4:1，几何账非实验量）**反向**——「省账本付质量税」；
   KV 几何账（模块档 + 207M@2048=48MiB + 216M 三兄弟 @2048=128/32/8MiB 两套命名账）随 JSON 输出。
3. **速度副判据（单独报）**：repeat_kv 物化展开使 gqa4/mqa1 的 sec/step 可能**不降反升**——如实报，
   「省的是显存带宽不是 FLOPs」的现场教学点（与 MQA 论文带宽论呼应，正文注明本机口径差异）。
4. 参数差如实标注：三臂总参 23,621,632 / 22,048,768 / 20,869,120（注意力槽差量，脚本 assert 锁死）。
