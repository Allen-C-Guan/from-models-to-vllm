# 导览：沿GPT蓝本理解LLaMA组件

> 带着一个问题读：**从GPT-2的蓝本走向LLaMA式模型，每个部件为什么改变，改变后又要检查什么？**本册先给出整机和阅读路线，具体推导与实验在后续章节展开。207M、48MiB等数字都带有配置条件，不代表任意LLaMA模型或设备。

Book2已经建立了因果语言模型的蓝本：文本经过分词和嵌入，进入重复的注意力与前馈Block，再得到下一词元分布。本册沿这台机器继续改造。问题不再只是怎样构造预训练任务，而是怎样让部件更适合训练、位置表示和增量生成的约束。

LLaMA是本册的整机案例。它组合了已有研究中的RMSNorm、SwiGLU和RoPE，并用公开来源数据进行大规模训练。其价值不能简单概括为“什么都没发明”，也不能把它写成所有后续模型唯一的祖先。对学习架构的人而言，这个案例提供了一条清晰路线：先理解单个组件想获得的性质，再检查多个组件如何在同一计算图中配合。

教学蓝本会经历四类替换和一个出入口调整：归一化、前馈、位置、KV头组织，以及输入输出权重解绑。我们尽量保留pre-norm残差Block的基本拓扑，让每次变化可定位；但投影形状、参数量、缓存接口和初始化都需要重新检查。所谓“插件式改造”不是保证任意零件可以直接插上，而是要求把替换的边界与连带影响说明白。

> **最小背景栏**：本册只假设你完整读过 Book1（能独立写出 2017 年 Transformer：多头注意力与三种角色、因果掩码、post-LN 与 FFN 数据流、正弦位置编码、参数账本——Book1 对应章节）与 Book2（理解GPT-2的结构与训练流程；实际完成长训练不是先修要求：四改造、分词器与词表、scaling laws、工程账本——Book2 第 2/4/8/9/10-11 章）。除此之外自包含：每个新组件都先教到「你能凭书稿画出它」再投入使用。

## 0.1 读完这本书，你会拥有什么

先说清目的地。合上这本书时，你会有三样东西：

**第一，一台能沿组件来源检查的LLaMA式207M模型，以及配套运行设计。**Book2的GPT-2既是教学比较蓝本，也供部分模块消融直接导入后换件；本册的共用组件库与逐章实现则提供新组件及数值参照。第2—6章分别解释归一化、前馈、位置编码、输入输出解绑与KV头组织，第10章再将第2/3/4/6章的组件import进同一台整机。模块消融在GPT-2对象中替换指定子模块，第10章则另行组装整机；两种使用方式都应按实际import和配置核对。指定配置的总参数为207,119,360，第10章会逐项核对。完整训练入口和历史短训曲线继续保留，全量长训仍按既定实践范围暂缓；运行设计用于核对数据、配置与预算，换设备后还须重新检查依赖和实际吞吐。

**第二，四件组件的选型判断力。**RMSNorm、SwiGLU、RoPE、分组查询注意力（GQA，grouped-query attention）——每一件都按同样的顺序讨论：它解决什么现实问题、代价是什么、论文怎么验证、你自己在笔记本上运行消融实验后观察到什么。读完你应该能回答这样一个选型问题：下一台机器，这个位置是否采用它？为什么？

**第三，一本KV缓存容量账。**第6章从因果生成解释为什么历史K/V可以复用，再按层数、KV头数、每头宽度、序列长度、批量和数值精度计算张量载荷。例如本册207M配置在单条2048-token序列、每元素2字节时，K/V合计48MiB；它不含模型权重、临时激活或分配器预留。验证时将手算与实际张量的元素数、元素字节数对齐，而不把这些载荷当成进程显存峰值。长度增加确实会推高存储需求，但模型能否可靠使用更长上下文，还要看位置、训练覆盖与任务表现。

这些成果之外，还有一种比较方法：先分清正在改变哪个量，再讨论收益。查询头数、KV头数和每头维度不是同一个变量；固定其他几何时，把16组KV改为8组，缓存载荷减半，却不能由此保证质量不变。2017年关于多头与头维的实验，也不能直接替代后来GQA的质量—成本比较。每章小结都会回到同一个问题：**这项机制留下了怎样的判断方法，使用它时必须保留哪些条件？**

## 0.3 先看一眼我们要造的机器

出发前先看图0.1的完整数据流，再看其中一层Block的放大图。上部连接输入、12层主体和词表输出；下部把四类组件改动放回同一残差块。与Book2图0.1对照时，既看保留的职责，也看新几何和接口。

![图 0.1](figures/fig-0-1-llama-207m-overview.png)

图0.1 本册LLaMA式207M模型的结构示意。上部为整机，下部为一层Block；①归一化、②前馈、③RoPE、④GQA分别对应第2/3/4/6章，U表示独立输出头。几何为$d=1024,L=12,h=16,h_{kv}=8,d_{ff}=2816,V=32000$。残差流始终为$(B,n,1024)$，两路注意力头的形状分别为$(B,16,n,64)$和$(B,8,n,64)$。依据本册配置与逐章组件代码绘制；它是教学示意，不是性能实验，也不代表所有LLaMA型号。

沿数据流从左到右看一遍，记住五处改动的位置——第 2-6 章介绍每项改动时，都会回到这张图定位：

- **入口少了一张表**：token 查表 $w_{te}$（形状 $(32000,\,1024)$）之上，GPT-2 那张 1024 行的位置查表 $w_{pe}$ 整件拆除（在上部数据流中已不再出现）——位置信息改在每层注意力的 Q 与 K 上现做，这就是插座③（第 4 章），全书数学最重的一章；
- **每层 Block 中替换两类组件**：两处归一化从LayerNorm换成RMSNorm，整机末端也作同样替换（插座①，第 2 章）；前馈从 GELU 两矩阵换成 SwiGLU 三矩阵带门，隐藏维先按$\frac{8}{3}d$估计，再向上取到256的倍数，本配置为2816（插座②，第 3 章）；
- **注意力改变了 KV 头的共享方式**：16 个查询头共享 8 组 KV 头（$h$=16、$h_{kv}$=8），不再是 16 个查询头各自使用一组 KV 头——这是插座④（第 6 章），也是明确 KV 存储成本后顺理成章的一项改动；
- **输出层改用独立权重**：输出头保存独立的$(32000,1024)$权重，不再与输入嵌入共用参数。读出将$(B,n,1024)$映射为$(B,n,32000)$的logits，softmax才得到概率。解绑与词表从50257改为32000分别影响参数量，第5章会把两笔变化拆开核算。

除这五处，其余零件——残差流、Block 拓扑、单塔 decoder-only——保留主要组织关系，细部配方仍须逐项核对；宽度从 768 涨到 1024、层数仍是 12。因此，本册实现模型的方法与 Book2 一脉相承：不是重造，是改装。

## 0.6 阅读范围与实践方式

本册以LLaMA1—3为组件主线，Llama 4仅用于说明如何由配置和实现重建结构。更晚的型号不是衡量本册完整性的标准；重要的是理解归一化、门控、位置和状态管理的机制，并能识别它们在新模型中的变化。专家模型、状态压缩、混合架构和服务调度，分别在后续各册展开。

207M实践提供组件实现、整机组装、参数核算、训练入口与运行设计。完整长训不属于阅读本册的必要条件。正文的MPS实验是2026年10月的历史记录，短算例与论文结果分别标明来源；设备、依赖和语料不同，不能保证重复得到相同耗时或末位数值。数据与权重不随书打包，运行实践需要按脚本说明取得资源。

数学推导单元先交代结论、用途和模型意义，再展开计算。只读首段可先建立路线；需要判断一个替换是否合理时，应回到它的假设、形状和证据边界。章节末尾的小结把局部机制放回整机，实践部分则帮助检查能够被数值验证的关系。

接下来先讨论整机选型：在达到所需能力的前提下，为什么可能愿意多花一些训练计算，换取一个使用成本更低的模型？这个问题会决定后面组件改造究竟服务哪些约束。
