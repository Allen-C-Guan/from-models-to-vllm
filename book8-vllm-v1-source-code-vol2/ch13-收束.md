## 13.5 带走的心智（全丛书终章版）

三章收束成三句话。**其一，「导航图先于细节」**：任何引擎、任何版本，先画出请求的生命周期（或专题的地界图）就永远不迷路——这套书的每一册都在教这个手艺。**其二，「每笔账有家」**：性能数字不是孤立的——每个加速比背后有一笔机制账（α/通信税/临界比/准入上限），能算账的人才能预测明天的数字。**其三，「双轨是纪律」**：读源码与跑实验互为印证、生产化从可观测开始——从第一册的 toy 走量到本册的 serve 对拍，这条「先理解、再验证、后信任」的路是工程和科研的共同根基。
